# ApkEditor·Miuix 小白编译教程（零环境版）

> 本项目是 **Android 应用**（UI 预览版 v0.1），需要一台电脑 + 一部 Android 15 手机。
> 你不需要提前安装任何环境——只需要 **Android Studio** 一个软件，其余全部自动下载。

---

## 一、需要准备什么

| 物品 | 要求 | 说明 |
| --- | --- | --- |
| 电脑 | Windows / macOS / Linux 均可 | 内存建议 8G 以上，硬盘剩余 20G 以上 |
| 手机 | Android 15（API 35）及以上 | 深色模式演示需要系统支持 |
| 数据线 | 手机连接电脑用 | 也可以用 WiFi 无线调试 |
| 网络 | 能访问 Google 服务 | 首次构建需下载依赖（约 1~2G） |

> ⚠️ 国内网络可能需要**科学上网**，否则 Gradle 下载依赖可能很慢或失败。
> 如果下载慢，可尝试把 `settings.gradle.kts` 里仓库换成阿里云镜像（见文档末尾）。

---

## 二、安装 Android Studio

1. 打开官网：https://developer.android.com/studio
2. 下载对应系统的安装包（Windows 选 `.exe`，macOS 选 `.dmg`，Linux 选 `.tar.gz`）
3. 一路默认安装即可（**不需要**勾选任何额外组件，Android SDK 会在首次建项目时自动装）

> 安装完成后第一次启动，会让你下载 Android SDK，点"Next"继续即可，保持默认。

---

## 三、解压源码并打开项目

1. 把你拿到的 **ApkEditorMiuix-完整包.zip** 解压，得到 `ApkEditorMiuix` 文件夹
2. 把 `ApkEditorMiuix` 文件夹放到一个方便的位置，例如 `D:\AndroidProjects\`
   - ⚠️ 路径**不要包含中文和空格**，否则 Gradle 可能报错
3. 打开 Android Studio：
   - 欢迎页选择 **Open**（打开）
   - 选中 `ApkEditorMiuix` 文件夹（选到能看到 `settings.gradle.kts` 的那一层）
   - 点击 **OK**
4. 首次打开会弹出 "Trust Project"（信任项目）→ 点 **Trust Project**

---

## 四、等待 Gradle 同步（关键步骤，耐心等）

1. Android Studio 右上角会自动开始 **Gradle Sync**（下方进度条在转）
2. 第一次同步需要：
   - 自动下载 Gradle 8.11（约 120MB）
   - 自动下载 Android SDK 37 平台（约 150MB）
   - 自动下载所有依赖库（约 500MB~1G）
3. **判断成功的标志**：右下角提示 "Sync Complete"，且没有红色报错

> ⚠️ 常见问题：
> - 如果一直卡在下载：多半是网络问题，参考文档末尾"网络镜像配置"
> - 如果提示 "SDK location not found"：点右侧提示链接，让它自动安装 SDK
> - 如果报 Java 版本错误：Android Studio 自带 JDK 17，不用手动装（File → Settings → Build Tools → Gradle → Gradle JDK 选 17 或 21）

---

## 五、编译出 APK

方式 A：命令行编译（推荐，最直观）

1. 打开终端（Windows 用 PowerShell，macOS/Linux 用 Terminal）
2. 进入项目目录：
   ```
   cd D:\AndroidProjects\ApkEditorMiuix
   ```
3. 运行：
   ```
   ./gradlew assembleDebug
   ```
   （Windows 上如果报错，改用 `gradlew.bat assembleDebug`）
4. 第一次运行会比较久（5~15 分钟），耐心等
5. **成功标志**：输出 `BUILD SUCCESSFUL`
6. APK 生成在：
   ```
   app/build/outputs/apk/debug/app-debug.apk
   ```

方式 B：Android Studio 界面操作

1. 菜单栏点 **Build → Build APK(s)**
2. 底部 Build 窗口出现 `BUILD SUCCESSFUL` 即成功
3. 点通知栏的 **locate** 可以直接打开 APK 所在文件夹

---

## 六、安装到手机

### 方式一：数据线（最简单）
1. 手机开启 **开发者选项**（设置 → 关于手机 → 连点版本号 7 次）
2. 打开 **USB 调试**
3. 数据线连接电脑，手机弹窗点"允许"
4. Android Studio 工具栏点绿色 **▶ Run**，选你的手机，自动安装运行

### 方式二：手动安装 APK
1. 把 `app-debug.apk` 传到手机（微信/QQ/网盘/数据线均可）
2. 手机文件管理器点开这个 apk
3. 系统提示"未知来源应用"→ 允许安装
4. 安装完成打开即可

## 七、验证功能（v0.2.0 新增）

### 1. 深色模式跟随系统
1. 打开 App → 主页
2. 切到手机系统 **设置 → 显示 → 深色模式**（开启）
3. 回到 App：所有界面应自动变为深色
4. 关闭深色模式：自动恢复浅色

> 如果切了没反应，说明装的是旧版，请确认安装的是 v0.2.0 及以后版本。

### 2. 底部三栏导航
1. 底部应有三个 Tab：**主页 / 保存的 APK / 设置**
2. 点「设置」→ 应看到主题选项和关于信息
3. 点「保存的 APK」→ 无记录时显示空状态提示

### 3. 设置页切换主题
1. 进入「设置」→ 点「主题」下拉
2. 选「深色」→ 立即变深色；选「浅色」→ 立即变浅色；选「跟随系统」→ 回到系统决定

### 4. 保存的 APK
1. 主页选任意 APK → 信息页点「打包并签名」→ 选择保存位置（任意名字 .apk）
2. 切到「保存的 APK」→ 出现刚才的打包记录
3. 点「分享」→ 系统分享面板；点「删除」→ 记录移除

## 八、网络镜像配置（国内网络下载慢时用）

打开 `settings.gradle.kts`，把仓库部分替换为阿里云镜像：

```kotlin
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        maven("https://maven.aliyun.com/repository/google")
        maven("https://maven.aliyun.com/repository/central")
        maven("https://maven.aliyun.com/repository/gradle-plugin")
        maven("https://jitpack.io")
        google()
        mavenCentral()
    }
}
```

再打开根目录 `build.gradle.kts`，把 plugins 块改为在本地仓库解析插件：

```kotlin
buildscript {
    repositories {
        maven("https://maven.aliyun.com/repository/google")
        maven("https://maven.aliyun.com/repository/gradle-plugin")
        mavenCentral()
    }
}
```

> 注意：插件版本请以项目内实际版本为准，不要随意改动。

## 九、常见报错速查

| 报错 | 原因 | 解决 |
| --- | --- | --- |
| `SDK location not found` | 没装 SDK | Android Studio 里 File → Settings → SDK，安装 Platform 37 |
| `Could not resolve ... miuix` | 依赖下载失败 | 检查网络，或用阿里云镜像 |
| `Unsupported class file major version 65` | JDK 版本不对 | Gradle JDK 设为 17 |
| `AAPT2 error` | 资源编译问题 | Build → Clean Project 再重试 |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 旧版签名冲突 | 先卸载旧版 App 再装 |
| `INSTALL_FAILED_VERSION_DOWNGRADE` | 降级安装 | 卸载旧版再装 |
| 手机上"解析包时出现问题" | APK 下载损坏 | 重新传一次 APK |

## 十、总结

到这里你就成功编译并安装了一个 **Miuix 风格（小米 HyperOS 外观）** 的 APK 编辑工具 UI。
当前版本界面全部可用，但数据是**演示数据**（mock），还没有接入真实的 APK 解析/反编译能力。
后续接入真实引擎后，将支持：DEX 反汇编为 Smali 并编辑、ARSC 资源表修改、二进制 XML 解码编辑、打包签名。

有任何一步卡住，把报错信息贴回来即可。

> v0.1-可靠重打包版：重打包改为「zip 拷贝 + 只替换修改过的文件」，未修改的内容直接回编译产物与原 APK 一致，保证可用；反编译目录用 smali/smali_classesN 标签对应各 dex。
