# ApkEditor·Miuix 小白编译教程（零环境版）

> 本项目是 **Android 应用**（UI 预览版 v0.1），需要一台电脑 + 一部 Android 15 手机。
> 你不需要提前安装任何环境——只需要 **Android Studio** 一个软件，其余全部自动下载。

---

## 一、需要准备什么

| 物品 | 要求 | 说明 |
| --- | --- | --- |
| 电脑 | Windows / macOS / Linux 均可 | 内存建议 8G 以上，硬盘剩余 20G 以上 |
| 手机 | Android 15（API 35）及以上 | 深色模式演示需要系统支持 |
| 数据线 | 手机连接电脑用 | 也可以用 WiFi 无线调试 |
| 网络 | 能访问 Google 服务 | 首次构建需下载依赖（约 1~2G） |

> ⚠️ 国内网络可能需要**科学上网**，否则 Gradle 下载依赖可能很慢或失败。
> 如果下载慢，可尝试把 `settings.gradle.kts` 里仓库换成阿里云镜像（见文档末尾）。

---

## 二、安装 Android Studio

1. 打开官网：https://developer.android.com/studio
2. 下载对应系统的安装包（Windows 选 `.exe`，macOS 选 `.dmg`，Linux 选 `.tar.gz`）
3. 一路默认安装即可（**不需要**勾选任何额外组件，Android SDK 会在首次建项目时自动装）

> 安装完成后第一次启动，会让你下载 Android SDK，点"Next"继续即可，保持默认。

---

## 三、解压源码并打开项目

1. 把你拿到的 **ApkEditorMiuix-完整包.zip** 解压，得到 `ApkEditorMiuix` 文件夹
2. 把 `ApkEditorMiuix` 文件夹放到一个方便的位置，例如 `D:\AndroidProjects\`
   - ⚠️ 路径**不要包含中文和空格**，否则 Gradle 可能报错
3. 打开 Android Studio：
   - 欢迎页选择 **Open**（打开）
   - 选中 `ApkEditorMiuix` 文件夹（选到能看到 `settings.gradle.kts` 的那一层）
   - 点击 **OK**
4. 首次打开会弹出 "Trust Project"（信任项目）→ 点 **Trust Project**

---

## 四、等待 Gradle 同步（关键步骤，耐心等）

1. Android Studio 右上角会自动开始 **Gradle Sync**（下方进度条在转）
2. 第一次同步需要：
   - 自动下载 Gradle 9.6（约 150MB）
   - 自动下载 Android SDK 37 平台（约 150MB）
   - 自动下载所有依赖库（约 500MB~1G）
3. **判断成功的标志**：右下角提示 "Sync Complete"，且没有红色报错

> ⚠️ 常见问题：
> - 如果一直卡在下载：多半是网络问题，参考文档末尾"网络镜像配置"
> - 如果提示 "SDK location not found"：点右侧提示链接，让它自动安装 SDK
> - 如果报 Java 版本错误：Android Studio 自带 JDK 17，不用手动装（File → Settings → Build Tools → Gradle → Gradle JDK 选 17 或 21）

---

## 五、编译出 APK

方式 A：命令行编译（推荐，最直观）

1. 打开终端（Windows 用 PowerShell，macOS/Linux 用 Terminal）
2. 进入项目目录：
   ```
   cd D:\AndroidProjects\ApkEditorMiuix
   ```
3. 运行：
   ```
   ./gradlew assembleDebug
   ```
   （Windows 上如果报错，改用 `gradlew.bat assembleDebug`）
4. 第一次运行会比较久（5~15 分钟），耐心等
5. **成功标志**：输出 `BUILD SUCCESSFUL`
6. APK 生成在：
   ```
   app/build/outputs/apk/debug/app-debug.apk
   ```

方式 B：Android Studio 界面操作

1. 菜单栏点 **Build → Build APK(s)**
2. 底部 Build 窗口出现 `BUILD SUCCESSFUL` 即成功
3. 点通知栏的 **locate** 可以直接打开 APK 所在文件夹

---

## 六、安装到手机

### 方式一：数据线（最简单）
1. 手机开启 **开发者选项**（设置 → 关于手机 → 连点版本号 7 次）
2. 打开 **USB 调试**
3. 数据线连接电脑，手机弹窗点"允许"
4. Android Studio 工具栏点绿色 **▶ Run**，选你的手机，自动安装运行

### 方式二：手动安装 APK
1. 把 `app-debug.apk` 传到手机（微信/QQ/网盘/数据线均可）
2. 手机文件管理器点开这个 apk
3. 系统提示"未知来源应用"→ 允许安装
4. 安装完成打开即可

## 七、验证功能（v0.2.0 新增）

### 1. 深色模式跟随系统
1. 打开 App → 主页
2. 切到手机系统 **设置 → 显示 → 深色模式**（开启）
3. 回到 App：所有界面应自动变为深色
4. 关闭深色模式：自动恢复浅色

> 如果切了没反应，说明装的是旧版，请确认安装的是 v0.2.0 及以后版本。

### 2. 底部三栏导航
1. 底部应有三个 Tab：**主页 / 保存的 APK / 设置**
2. 点「设置」→ 应看到主题选项和关于信息
3. 点「保存的 APK」→ 无记录时显示空状态提示

### 3. 设置页切换主题
1. 进入「设置」→ 点「主题」下拉
2. 选「深色」→ 立即变深色；选「浅色」→ 立即变浅色；选「跟随系统」→ 回到系统决定

### 4. 保存的 APK
1. 主页选任意 APK → 信息页点「打包并签名」→ 选择保存位置（任意名字 .apk）
2. 切到「保存的 APK」→ 出现刚才的打包记录
3. 点「分享」→ 系统分享面板；点「删除」→ 记录移除
4. （2026-10-03 新增）用文件管理器把输出的那个 APK 文件删掉 → 重进「保存的 APK」页 → 失效记录应自动消失

### 5. 代码编辑器：查找替换（新增）
1. 主页选 APK → 信息页进入 **DEX / Smali** → 选一个 dex → 点开任意 smali 文件
2. 右上角有个**放大镜**图标，点它会弹出底部「查找替换」面板
3. 在「查找」里输入内容 → 点「下一个」/「上一个」可在匹配处跳转，标题栏会显示 `当前/总数`
4. 在「替换为」里输入内容 → 点「替换」换掉当前一处，点「全部替换」换掉全部
5. 面板上还有两个可点的小开关：**Aa 区分/忽略大小写**、**.* 普通/正则**
6. 右上角**三个点**菜单里还有：跳转到行、撤销、重做、保存、退出
7. 编辑后标题栏文件名后面会出现 `*`，底部状态行显示「有未保存修改」，保存后变回「已保存」

> 注意：「替换」和「全部替换」必须先点过一次「下一个」完成查找，否则会提示「请先查找」。

### 6. 顶栏统一（新增）
从 APK 内容页往下走的这些页面，顶栏现在长得一样了：**左边一个返回箭头**（不再额外显示「返回」两个字），**右边放大镜**（点开页内搜索框）和**三个点**（更多菜单）。

按这个顺序点一遍就能看出效果：
1. 主页选 APK → 进 APK 内容页（顶栏是应用名，左边只有箭头）
2. 点 `resources.arsc` → 资源类型页 → 点任一类型 → 资源条目页（右上角出现放大镜，点它才展开搜索框）
3. 返回，点 `classes.dex` → Smali 树 → 点右上角三个点，里面是「汇编」
4. 点「全部 DEX 同时反编译」也行；汇编完会弹窗告诉你结果，而不是像以前那样把文字错位叠在页面上

> 注意：**设置、保存的 APK、关于**这几个页面的顶栏是另一套设计（带滚动折叠和背景模糊），这次没有改。

### 7. 打包（本次修复，重要）
之前版本打包会直接失败，提示 `STORED entry missing size, compressed size, or crc-32`——因为现代 APK 里的 `resources.arsc` 和 `lib/*.so` 都是**不压缩**存储的，旧代码写回时没给这些条目的校验信息，`ZipOutputStream` 直接拒绝。现在已修好，并且**补上了对齐**（zipalign）。

⚠️ **打包默认不签名**（本次新增的设置）：默认产物是 `xxx-unsigned.apk`，**未签名的 APK 装不上手机**。要装的话先打开签名开关：

1. 底部切到「**设置**」
2. 找到「输出目录」那一块，把「**打包时签名**」打开（默认关闭）
3. 回到主页选 APK，打一次包会生成自签名密钥（首次稍慢），产物名为 `xxx-signed.apk`

验证方法：
1. 主页选一个 APK → 进 APK 内容页
2. 点最下面的「**打包并签名（输出到统一目录）**」，什么也不改
3. 应该弹出「打包完成」，并在输出目录里得到产物
4. 确认签名开关已开后，把产物装到手机上——**未修改直接打包的产物应该能和原 APK 一样正常安装运行**

> 如果装的时候报「解析软件包时出现问题」或装了打不开，把手机型号和具体提示发回来。

### 8. 修改不再丢失（本次修复）
之前版本有一个严重问题：**改完 ARSC 或 DEX，返回 APK 信息页再回去，修改就没了**。原因是每次进入信息页都会把 APK 重新解析一遍，顺手把"待应用的修改"一起清掉了。现在已修好：**待应用的修改会一直保留，直到你自己打包或者主动放弃**。

验证方法：
1. 选一个 APK → 进 APK 内容页 → 点 `resources.arsc` → 进资源类型 → 选一个类型 → 点某个资源改个值并保存
2. **按返回键回到 APK 信息页**
3. 再进 `resources.arsc` → 找到刚才那条资源 → **值应该还是你改的**
4. 然后点「打包并签名」，产物里就带着这个修改

另外新增了「**放弃所有修改**」：在 APK 信息页点右上角**三个点**就能看到，会把 DEX / 资源 / XML 的未打包修改全部丢掉，回到原始 APK 状态（会弹窗二次确认）。想重新开始时用它。

### 9. MT 式类/方法导航 + 高亮（本次新增）

1. 打开 APK → 进入 DEX → Smali 目录树，点任意 `xxx.smali` 文件，现在进入的是**类详情页**：
   上方是类信息（类名 / 访问标志 / 父类 / 接口），下方是**方法列表**。
2. 顶栏**返回键右边有一个指南针图标**，点它打开「所有类」列表（跨 DEX、可搜索），
   点任意类可直接切到那个类的方法列表。
3. 点某个方法 → 进入**单方法编辑**：只显示这一个方法的代码，保存只回写这个方法块（更安全）。
   想编辑整个文件，用类详情页右上角 More 菜单里的「编辑整个文件」。
4. 编辑器里 `​.method` 和 `​.end method` 两行现在有**整行红色背景**，方法边界一目了然。
5. smali 编辑有真正的**语法高亮**（指令/寄存器/字符串/类型/标签着色）和 dalvik 指令补全；
   XML 编辑也有 XML 高亮；编辑器底色、行号、正文颜色跟随 app 主题——**深色模式和 Monet 取色都会同步**。
6. **交互与顶栏（本次更新）**：
   - smali 目录里点文件 → 直接进整文件编辑；顶栏返回右边的**列表图标** = 方法列表（More 菜单里也有「方法列表」）
   - APK 详情页顶栏滚动自动缩小、折叠后模糊，标题固定「详情」
   - 详情页头部图标现在是 **APK 里的真实应用图标**（不再是首字母色块）
   - 关于页新增「应用信息」卡（真实版本/包名/引擎版本）；第三方许可证列表已与实际依赖对齐
   - 主页：**点顶栏返回上一级目录**，**长按顶栏弹窗输入路径跳转**，子目录里按**返回键逐级返回**

### 10. XML 编辑往返（2026-10-03 修复）
1. 主页选 APK → 信息页「XML」→ 打开任意 `res/layout` 或 `AndroidManifest.xml`
2. 确认内容里有 `xmlns:android="http://schemas.android.com/apk/res/android"` 声明和 `android:xxx` 前缀属性（修复前会全部丢失）
3. 不改动直接保存 → 打包 → 产物安装/打开后界面与资源表现正常（字符串值无污染、含 & 的文本不损坏）
4. 解码出的 XML 带 4 空格缩进、可正常阅读（AndroidManifest 不再挤成一行），xmlns 声明统一在根元素上

### 11. UI 修正（2026-10-03）
1. **关于页**：「应用版本 / 作者」两行可点击（跳转项目 GitHub 主页）+ 许可证卡（项目许可证为 GNU GPL v3.0，第三方许可证入口保留且清单已按实际依赖校准）
2. **设置页**：没有「崩溃日志」行；滚到底时最后一项不被底栏遮挡
3. **反编译目录页**（DEX / Smali / XML / 资源）：下滚时顶栏自动缩小，折叠后背景渐进模糊（与主页观感一致）

## 八、网络镜像配置（国内网络下载慢时用）

打开 `settings.gradle.kts`，把仓库部分替换为阿里云镜像：

```kotlin
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        maven("https://maven.aliyun.com/repository/google")
        maven("https://maven.aliyun.com/repository/central")
        maven("https://maven.aliyun.com/repository/gradle-plugin")
        maven("https://jitpack.io")
        google()
        mavenCentral()
    }
}
```

再打开根目录 `build.gradle.kts`，把 plugins 块改为在本地仓库解析插件：

```kotlin
buildscript {
    repositories {
        maven("https://maven.aliyun.com/repository/google")
        maven("https://maven.aliyun.com/repository/gradle-plugin")
        mavenCentral()
    }
}
```

> 注意：插件版本请以项目内实际版本为准，不要随意改动。

## 九、常见报错速查

| 报错 | 原因 | 解决 |
| --- | --- | --- |
| `SDK location not found` | 没装 SDK | Android Studio 里 File → Settings → SDK，安装 Platform 37 |
| `Could not resolve ... miuix` | 依赖下载失败 | 检查网络，或用阿里云镜像 |
| `Unsupported class file major version 65` | JDK 版本不对 | Gradle JDK 设为 17 |
| `AAPT2 error` | 资源编译问题 | Build → Clean Project 再重试 |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 旧版签名冲突 | 先卸载旧版 App 再装 |
| `INSTALL_FAILED_VERSION_DOWNGRADE` | 降级安装 | 卸载旧版再装 |
| 手机上"解析包时出现问题" | APK 下载损坏 | 重新传一次 APK |

## 十、总结

到这里你就成功编译并安装了一个 **Miuix 风格（小米 HyperOS 外观）** 的 APK 编辑工具。
应用已接入真实反编译引擎，可以真实地反编译 DEX/XML、编辑并回编译签名。
后续将支持：MT 式的「类列表 → 方法列表 → 单方法编辑」、打包前 zipalign 对齐等。

有任何一步卡住，把报错信息贴回来即可。

> v0.1-可靠重打包版：重打包改为「zip 拷贝 + 只替换修改过的文件」，未修改的内容直接回编译产物与原 APK 一致，保证可用；反编译目录用 smali/smali_classesN 标签对应各 dex。
